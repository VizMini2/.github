# .github

Organization-wide defaults for **VizMini2**:

| File | Purpose |
|---|---|
| `profile/README.md` | Public profile shown on <https://github.com/VizMini2> |
| `ISSUE_TEMPLATE/` | Bug report and feature request forms; blank issues disabled |
| `pull_request_template.md` | Checklist shown when opening a pull request |
| `CONTRIBUTING.md`, `SUPPORT.md`, `SECURITY.md` | Linked by GitHub from issues, pull requests and the Security tab |
| `FUNDING.yml` | "Sponsor" button (GitHub Sponsors) |

These files apply to every repository in the organization that does not have its
own version of them.
